# Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| **F1** | Open this manual |
| **Ctrl+N** | New scene |
| **Ctrl+O** | Open a project |
| **Ctrl+S** | Save the scene |
| **Ctrl+Shift+S** | Save the scene as |
| **Ctrl+D** | Duplicate the selected entity |
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** / **Ctrl+Y** | Redo |
| **Ctrl+R** | Reload the C# scripts |
| **Ctrl+Shift+R** | Reload all shaders |
| **Ctrl+B** | Bookmark the selected entity |
| **Ctrl+Shift+P** | Command palette |
| **Q W E R** | Gizmo: none, move, rotate, scale |

The camera controls are in [Scene View and Camera](viewport). The command palette lists every command with its shortcut, so it is the quickest way to find one.

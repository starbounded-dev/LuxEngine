# 2D: Sprites, Circles and Text

Create these from **Create 2D** in the Scene Hierarchy's menu. [Your First 2D Game](../getting-started/2d-game) uses all of them. They are drawn as flat shapes in the scene, facing +Z, and use the entity's [Transform](transform).

| Component | Draws |
|---|---|
| **Sprite Renderer** | A coloured or textured rectangle. **Texture** and **Tiling Factor** repeat an image across it. **Sheet** and **Frame** show one sprite of a [sprite sheet](#sprite-sheets-and-animation) instead. **Point Filter** keeps pixel art sharp. |
| **Sprite Animator** | Plays one of the sheet's animation clips on the Sprite Renderer beside it. |
| **Circle Renderer** | A filled circle or ring (**Thickness**), with a soft edge (**Fade**). |
| **Text** | Text in any font, with colour, **Max Width** for wrapping, line spacing and an optional drop shadow. **Screen Space** keeps it on screen like a user interface. |

A scene can use any number of textures and fonts at once.

## Draw order

Sprites, circles and text are drawn by **Sorting Layer**, then **Order In Layer**, then depth (farther first). Sorting layers are listed in **Project Settings > 2D**, back to front; add, rename and reorder them there. **Default** always exists. Within one kind, a higher order draws on top; text and circle outlines draw after sprites. Clicking where sprites overlap in the Scene View selects the one drawn on top.

A **Camera** with **Pixel Perfect** on shows a whole number of screen pixels per sprite pixel (**Pixels Per Unit**, and a **Reference Height** that sets the scale) and sits on the pixel grid. Turn on **Point Filter** on pixel-art sprites so they are not blurred.

## Sprite sheets and animation

A **sprite sheet** (**Create > Sprite Sheet** in the Content Browser, with a texture selected) cuts one texture into frames and holds the animation clips that play them. Double-click it to open the Sprite Sheet Editor: pick the texture, set the **Cell Size** (and spacing and margin) and press **Cut Into Frames**, then click a frame to name it and set its **Pivot**. **Add Clip** makes a clip from a list of frame numbers (`0, 1, 4-6`), with **Frames Per Second** and **Wrap** (Once, Loop or Ping Pong); the preview shows it playing. A frame's world size is its size in pixels divided by the sheet's **Pixels Per Unit**.

To animate an entity, give its Sprite Renderer the sheet and add a **Sprite Animator** with the clip. To build a sheet from many single images, select the textures and choose **Create > Sprite Atlas From Selected Textures**: they are packed into one image and a sheet with one named frame each. Sheets and their textures are included in an exported game like any asset.

```
SpriteAnimatorComponent animator = GetComponent<SpriteAnimatorComponent>();
animator.Play(velocity.X != 0 ? "run" : "idle");   // a clip that is already playing keeps going
```

## 2D physics

2D physics uses its own components, which simulate in the X/Y plane with Box2D. A **Rigidbody 2D** makes the entity a body (static, dynamic or kinematic); every collider on the same entity is part of that body.

| Collider | Shape |
|---|---|
| **Box Collider 2D** | A rectangle (**Size** is half the width and height, scaled by the entity's scale). |
| **Circle Collider 2D** | A circle. |
| **Polygon Collider 2D** | A convex polygon of 3 to 8 points; points that are not convex are replaced by their hull. |
| **Capsule Collider 2D** | A rounded rectangle, vertical or horizontal, from a **Radius** and a total **Height**. |
| **Edge Collider 2D** | A line of two or more points, open or closed (**Loop**): floors, walls and terrain. It has no area, so put it on a static body. |

Every collider has **Friction**, **Restitution** and, except the edge, **Density**. **Is Trigger** makes a collider detect overlaps (**OnTriggerBegin** and **OnTriggerEnd** in a script) and block nothing. Tilemaps with solid tiles collide too.

A **Joint 2D** ties the entity's body to another body, or to a fixed point in the world when **Connected Body** is empty: **Distance** keeps two anchors a length apart (add **Stiffness** for a spring), **Revolute** is a hinge, **Prismatic** a slider along an **Axis**, **Weld** locks the two together. Hinge and slider can have limits and a motor. Joints are made when the scene starts.

The 2D world steps at the project's **Fixed Timestep** (**Project Settings > Physics**), the same clock as the 3D world, and a script's `OnFixedUpdate` runs before each step. Gravity comes from the project's **Gravity** (X and Y).

```
if (Physics2D.Raycast(Translation.XY, new Vector2(0.0f, -1.0f), out RaycastHit2D hit, 0.6f, this))
    grounded = true;                       // standing on something
Entity[] touching = Physics2D.OverlapCircle(Translation.XY, 1.5f);
```

## A 2D project

**New Project** offers a **2D game** template: an orthographic camera with a solid background, a ground and a falling box, and the Scene View opens in the 2D view. Middle or right drag pans it and the wheel zooms; the gear menu turns the 2D view on or off and sets **Pixel Snap**. Any project can switch with **Project Settings > 2D > Project Type**.

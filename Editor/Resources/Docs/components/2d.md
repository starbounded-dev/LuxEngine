# 2D: Sprites, Circles and Text

Create these from **Create 2D** in the Scene Hierarchy's menu. [Your First 2D Game](../getting-started/2d-game) uses all of them. They are drawn as flat shapes in the scene, facing +Z, and use the entity's [Transform](transform).

| Component | Draws |
|---|---|
| **Sprite Renderer** | A coloured or textured rectangle. **Texture** and **Tiling Factor** repeat an image across it. |
| **Circle Renderer** | A filled circle or ring (**Thickness**), with a soft edge (**Fade**). |
| **Text** | Text in any font, with colour, **Max Width** for wrapping, line spacing and an optional drop shadow. **Screen Space** keeps it on screen like a user interface. |

A scene can use any number of textures and fonts at once.

2D physics uses its own components, **Rigidbody 2D**, **Box Collider 2D** and **Circle Collider 2D**, which simulate in the X/Y plane.

## From a script

```
TextComponent label = GetComponent<TextComponent>();
label.Text = "Score: 10";
```

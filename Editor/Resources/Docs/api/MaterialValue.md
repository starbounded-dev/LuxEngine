# MaterialValue

`public enum MaterialValue`

The scalar values of a material that [`StaticMeshComponent.GetMaterialValue`](StaticMeshComponent) reads and writes.

## Values

| Name | Value | Description |
|---|---|---|
| `Metalness` | 1 | How metal the surface is, 0 to 1. |
| `Roughness` | 2 | How rough the surface is, 0 (mirror) to 1. |
| `Emission` | 3 | How much the surface glows, 0 or more. |
| `Transparency` | 4 | The opacity of a transparent material, 0 (invisible) to 1. |

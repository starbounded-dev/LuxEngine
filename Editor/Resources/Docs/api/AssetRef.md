# AssetRef

`public abstract class AssetRef`

The base of script fields that reference an asset. A public field of a derived type is assigned in the inspector by dragging the asset onto it.

## Fields

| Name | Type | Description |
|---|---|---|
| `Handle` | `ulong` | The asset's handle (its UUID), or 0 when the field is unassigned. |

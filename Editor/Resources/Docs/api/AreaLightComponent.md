# AreaLightComponent

`public class AreaLightComponent : LightComponent`

A light with a surface: a rectangle, disk, sphere or tube, set in the inspector.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Height` | `float` | get, set | The height of a rectangle light, in meters. |
| `Length` | `float` | get, set | The length of a tube light, in meters. |
| `Radius` | `float` | get, set | The radius of a disk, sphere or tube light, in meters. |
| `Range` | `float` | get, set | The distance in meters from the light's center where its influence has faded to nothing. |
| `TwoSided` | `bool` | get, set | Whether a rectangle or disk light shines from both faces. |
| `Width` | `float` | get, set | The width of a rectangle light, in meters. |

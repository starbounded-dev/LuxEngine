# SkyLightComponent

`public class SkyLightComponent : Component`

The light and reflections from the sky, the environment the scene sits in.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Intensity` | `float` | get, set | How bright the sky light is. Negative values become 0. |
| `Rotation` | `float` | get, set | Turns the sky, and the light it gives, about the vertical axis, in degrees. |

# CursorMode

`public enum CursorMode`

How the mouse cursor behaves over the game window, for [`Input.SetCursorMode`](Input).

## Values

| Name | Value | Description |
|---|---|---|
| `Normal` | 0 | Visible and free. |
| `Hidden` | 1 | Invisible over the window, but free to leave it. |
| `Locked` | 2 | Invisible and captured, for mouse-look: the position keeps changing without limit. |

# GamepadButton

`public enum GamepadButton`

A gamepad button in the standard layout, the same on every mapped controller. Face buttons are named by position: `South` is Xbox A / PlayStation Cross, `East` is B / Circle, `West` is X / Square and `North` is Y / Triangle.

# TextComponent

`public class TextComponent : Component`

Draws text in the world with an MSDF font.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Color` | `Vector4` | get, set | Color (RGBA, 0 to 1). |
| `Kerning` | `float` | get, set | Extra space between characters. |
| `LineSpacing` | `float` | get, set | Extra space between lines. |
| `MaxWidth` | `float` | get, set | Width at which lines wrap. |
| `Text` | `string` | get, set | The text; `\n` starts a new line. |

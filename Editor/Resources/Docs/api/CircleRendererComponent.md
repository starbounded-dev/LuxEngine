# CircleRendererComponent

`public class CircleRendererComponent : Component`

Draws a circle or ring (2D).

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Color` | `Vector4` | get, set | Color (RGBA, 0 to 1). |
| `Fade` | `float` | get, set | Edge softness; 0 is a hard edge. |
| `Thickness` | `float` | get, set | Ring thickness as a fraction of the radius: 1 is a filled disc. |

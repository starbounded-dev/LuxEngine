# UICanvasComponent

`public class UICanvasComponent : Component`

The root of a user interface: the elements under it are drawn over the game, scaled to the screen.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Visible` | `bool` | get, set | The same switch as [`Component.Enabled`](Component): a canvas that is off is neither drawn nor operated. |

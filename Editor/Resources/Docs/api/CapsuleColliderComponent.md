# CapsuleColliderComponent

`public class CapsuleColliderComponent : Component`

A capsule shape (along Y) for the entity's 3D rigid body or character.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `HalfHeight` | `float` | get, set | Half the height of the cylinder part, without the caps. |
| `Offset` | `Vector3` | get, set | The capsule's center relative to the entity. |
| `Radius` | `float` | get, set | The radius of the capsule's cylinder and caps. |

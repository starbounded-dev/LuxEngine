# AcousticGeometryMode

`public enum AcousticGeometryMode`

How a mesh takes part in ray-traced acoustics.

## Values

| Name | Value | Description |
|---|---|---|
| `Static` | 0 | Captured once at its starting transform. |
| `Dynamic` | 1 | Follows the entity as it moves. |
| `Disabled` | 2 | Not acoustic geometry. |

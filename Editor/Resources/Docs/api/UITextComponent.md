# UITextComponent

`public class UITextComponent : Component`

Text inside an element.

## Properties

| Name | Type | Access | Description |
|---|---|---|---|
| `Color` | `Vector4` | get, set | Color (RGBA, 0 to 1). |
| `Size` | `float` | get, set | The height of a line in UI units. |
| `Text` | `string` | get, set | The text; `\n` starts a new line. For a text input this is what the player typed. |
